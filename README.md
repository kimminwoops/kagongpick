# 카공픽 (KAGONGPICK) MVP

> 카공할 땐, 카공픽. — 공부 조건으로 찾는 대학생 카공 지도

빌드 도구 없이 동작하는 정적 웹앱입니다. (Leaflet 1.9.4 + OpenStreetMap 타일, Pretendard 폰트)

## 실행

**가장 쉬운 방법:** 폴더 안의 `카공픽.html`을 더블클릭하면 브라우저에서 바로 열립니다. 데이터가 파일 안에 들어 있어 서버가 필요 없습니다. (`assets` 폴더가 옆에 있어야 사진이 보입니다)

데이터를 고친 뒤 `카공픽.html`을 다시 만들려면:

```bash
powershell -ExecutionPolicy Bypass -File tools\build-artifact.ps1 -Out 카공픽.html -Standalone
```

로컬 서버로 보려면 `powershell -ExecutionPolicy Bypass -File serve.ps1` 후 http://localhost:5173 을 엽니다. GitHub Pages / Vercel에는 폴더 그대로 올리면 됩니다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 골격 (상단 바, 필터, 목록/상세 패널, 지도) |
| `styles.css` | 디자인 토큰(뮤트 파스텔 + 뉴트럴, 라운드 UI), 데스크톱/모바일 레이아웃 |
| `app.js` | 필터·검색, 지도 핀, 목록 동기화, 상세, 바텀시트, 내 위치 |
| `data/regions.js` | 지역 설정 (지역별 CSV 경로, 거리 기준점) |
| `data/cafes.csv` | 경북대 북문 카페 51곳 — 앱이 이 파일을 직접 읽음 |
| `assets/logo.svg` | 임시 라운드형 로고 — 확정 로고 파일로 교체 |

## 구현된 기능 (기획서 9장 완료 기준 대응)

- 로그인 없이 지도·목록·상세 열람
- 필터 6종(콘센트, 조용함, 넓은 테이블, 다인석, 늦게까지, 현재 영업 중) AND 조합 + 검색 → 핀과 목록 동시 반영, 결과 수·초기화
- `unknown`은 "정보 없음"으로 표시하며 `없음`과 구분, 필터에서는 제외
- 영업 상태: 한국 시간 기준, 자정 넘김 영업(`"26:00"`) 처리, 시간 미확인 표시
- 상세: 조건, 요일별 영업시간, 정보 출처·마지막 확인일, 길찾기 링크
- 모바일 바텀시트(접힘/절반/펼침, 드래그), 데스크톱 좌측 목록 + 우측 지도
- 안내 화면: 빈 결과, 위치 권한 거부, 데이터 로딩 실패, 지도 로딩 실패

## 카페 데이터 수정 (`data/cafes.csv`)

엑셀에서 열어 고치고 CSV로 저장하면 새로고침만으로 반영됩니다. (UTF-8 / CP949 둘 다 읽음)

| 열 | 입력 방법 |
|---|---|
| `outlets`, `large_tables`, `laptop_friendly` | `yes` / `no` / 비우거나 `unknown` (있음/없음, O/X도 가능) |
| `group_seating` | `yes`, `no`, 또는 인원 수(`6`) |
| `quiet_level` | `3`(조용함) / `2`(보통) / `1`(활기참) / 비우면 정보 없음 |
| `hours` | `매일 09:00-22:00` · `월-금 09:00-24:00; 토,일 11:00-23:00; 화 휴무` · `24시간` · 자정 넘김은 `10:00-02:00` |
| `hours_source` | 영업시간 출처 (예: `카카오맵 (2026-11-08 조회)`). 목록·상세에 "카카오맵 기준"으로 표시 |
| `photos` | 사용 권한 확인된 사진 URL, 여러 장은 `\|`로 구분 |
| `last_verified_at` | 현장 확인한 날짜(`2026-11-20`). 채우면 "확인된 정보"로 표시 |
| `check_note` | 채우면 목록·상세에 "현장 확인 필요"로 표시 |
| `naver_map_url`, `kakao_map_url` | 비어 있으면 네이버지도 검색 / 카카오맵 좌표 길찾기로 대체 |

`zone`, `floor`는 상세 주소 옆에 표시되고, `distance_m`은 쓰지 않습니다 (앱이 북문 또는 내 위치 기준으로 직접 계산).

## ⚠️ 출시 전 해야 할 일

1. 51곳 모두 공부 조건·영업시간이 비어 있어 "현재 영업 중", "콘센트 있음" 등 필터 결과가 0곳입니다. 현장 조사로 채워주세요.
2. `check_note`가 있는 곳(교내 좌표, 카카오맵 미등록·상호 변경 의심)은 현장 확인 후 제외하거나 메모를 지우세요.
3. 트래픽이 늘면 OSM 타일 이용 정책을 확인하고 카카오/네이버 지도 SDK 등으로 전환을 검토하세요.
4. 확정된 카공픽 로고로 `assets/logo.svg` 교체.
